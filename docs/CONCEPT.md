# Qadam: концепция

Qadam (каз. «шаг») — ИИ-советчик для прогулок по Астане. На вопрос «куда пойти рядом прямо сейчас» он отвечает 1–3 конкретными местами. Для каждого места сказано, почему оно подходит, сколько займёт времени и что там делать.

## Проблема
За минуту трудно понять, что интересного рядом и работает ли оно. Особенно тяжело туристу, человеку с ребёнком, ночью или в мороз. Карты показывают сотни точек без объяснений, а часы работы известны меньше чем у трети мест (28% POI в наших данных).

## Решение
- **Вход:** ориентир или H3-ячейка r10 (≈1,8 га), время и запрос на ru, kk или en (`RecommendRequest`).
- **Выход:** 1–3 карточки и мини-маршрут до трёх точек (`Answer`: `Card`, `MiniRoute`).
- **Факты считает код** по данным OpenStreetMap: расстояние, минуты пешком, часы, адрес. Claude пишет только «почему» и «что делать».
- **Метки на каждой карточке:** откуда идея (`idea_source`: данные POI или ИИ), источник фактов (`facts_sources`), уверенность в часах работы (`open_confidence`).
- **Панель «Какие данные использованы»** (`DataUsed`): место, время, погода, фильтры, источники, чем разобран запрос и чем написаны тексты.

## Чем отличаемся
1. **Честность.** Без надёжных данных не пишем «открыто сейчас», вместо этого просим проверить. Ответ «рядом почти ничего нет» тоже считается ответом (E11).
2. **Контекст.** Учитываем время UTC+5, погоду Open-Meteo, бюджет времени, детей, коляску, ночь и группу.
3. **Приватность.** Сервер не принимает координаты, только ячейку или ориентир. Подробнее в [ETHICS.md](ETHICS.md).
4. **Работает без ИИ.** Если Claude недоступен, ответ собирается по шаблонам из тех же данных (E10).

**Статус на 18.10.** В `main` есть всё: данные (1222 POI по Астане), ядро, генерация через Claude, API, веб-интерфейс и eval. Eval: 16/16 с Claude и 16/16 без него (подробности в [SCENARIOS.md](SCENARIOS.md)).
