# Промпты по волнам (копировать как есть)

Владелец: интегратор. Перед каждым промптом указано, **где** его запускать.

Где запускать:
- «Основная» — сессия на папке `D:\HACATHON` **без** worktree. Это интегратор, ветка `main`.
- «Новая worktree-сессия» — Claude Desktop → **+ New session** (Ctrl+N). Проект: `D:\HACATHON`, ветка: `main`, включить **worktree**. В CLI то же самое делает `claude --worktree <имя>`.

Режимы:
- Accept edits — режим по умолчанию (задан в `.claude/settings.json`).
- Где написано «Plan», перед отправкой переключи режим на Plan (Shift+Tab или переключатель режима у поля ввода). После одобрения плана верни Accept edits.

Модель: интегратор, CORE и LLM — сильная модель по умолчанию. DATA, WEB и EVAL можно перевести на `/model sonnet`, если упираетесь в лимиты.

## Команды на каждый день
- Статус всех дорожек (основная): `/integrate list`

- Контекст разросся: `/compact` (или `/ecc:save-session` и новая сессия → `/ecc:resume-session`)
- Сломалась сборка или импорт: `/ecc:build-fix`
- Быстрый побочный вопрос без засорения контекста: `/subtask <вопрос>`
- Перед любым мержем: `/code-review` в сессии дорожки
