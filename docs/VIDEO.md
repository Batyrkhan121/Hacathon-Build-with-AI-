# Qadam: демо-видео на 2:40 (раскадровка, черновик)

Формат: запись экрана 1920×1080, закадровый голос на русском, субтитры по желанию. Загрузка на YouTube с доступом по ссылке.
Запись: OBS (окно браузера + микрофон) или `/ecc:ui-demo` (Playwright, по сценам ниже).

Перед записью:
- Запустить API и UI: `uvicorn app.api:app --port 8000`, затем открыть http://localhost:8000.
- Прогреть кэш: один раз пройти все пресеты, чтобы ответы Claude брались из `data/cache/llm/` и не было пауз.
- Время в демо задаётся «машиной времени» в UI, так результат повторяем: S1 пн 19.10 15:00, S3 12:00, S5 23:30.
- Закрыть лишние вкладки, масштаб браузера 110%, курсор крупный.

## 1. Хук (0:00–0:10)
**На экране:** карта Астаны с сотнями точек, затем быстрый переход к пустому экрану Qadam со строкой запроса.

**Голос:**
> Сотни мест на карте — и ни одного ответа на вопрос «куда пойти рядом прямо сейчас». Это Qadam.

## 2. S1: прогулка у Mega Silk Way (0:10–0:45)
**На экране:**
1. Клик по пресету «Mega Silk Way · прогулка 30–60 мин», в строке появляется текст запроса.
2. 1–3 карточки и линия маршрута на карте.
3. Наезд на первую карточку: «почему», «сколько времени», «что делать».
4. Наезд на мини-маршрут: порядок, общее время, «в бюджете».
5. Курсор на метку «прямые отрезки × 1,3».

**Голос:**
> Сценарий из кейса: «Я возле Mega Silk Way, хочу прогуляться полчаса-час». Вместо списка — три карточки. В каждой написано, почему место подходит, сколько до него идти и что там сделать. Внизу маршрут, который укладывается в ваш час. И мы честно пишем, что маршрут приблизительный.

## 3. S3: с ребёнком (0:45–1:10)
**На экране:**
1. Пресет «С ребёнком» у EXPO.
2. Карточки: площадка, парк или ТРЦ, без баров. Площадка «Детская площадка» в ответе одна.
3. Наезд на чип фильтра «с ребёнком» в панели «Какие данные использованы».

**Голос:**
> Теперь я с ребёнком. Qadam понял это из текста и включил фильтр: баров и клубов в ответе нет. Площадок без названия в данных больше сотни, но в ответе такая одна — без трёх одинаковых карточек. Фильтр виден в панели «Какие данные использованы».

## 4. S5: ночь (1:10–1:40)
**На экране:**
1. Машина времени на 23:30, пресет «Ночная активность» у Хан Шатыра.
2. Только места, которые работают допоздна. Сверху предупреждение о безопасности.
3. Наезд на метку часов: «по данным OSM: … до 02:00» против «нет данных о часах, проверьте перед визитом».
4. Наезд на «до закрытия ≈ N мин».

**Голос:**
> Половина двенадцатого ночи. Остаются только места, которые по данным работают допоздна, и сверху предупреждение: выбирайте людные, освещённые места. Обратите внимание на уверенность. Где часы подтверждены, мы пишем, до скольких открыто. Где данных нет, так и пишем: «проверьте перед визитом». «Открыто сейчас» без данных Qadam не говорит никогда.

## 5. Приватность (1:40–2:00)
**На экране:**
1. Кнопка «Моё место», браузер спрашивает разрешение.
2. На карте закрашивается шестиугольник ячейки, а не точка.
3. Вставка во весь экран: DevTools → Network → тело запроса `{"location": {"h3_cell": "8921…"}}` без lat/lon.

**Голос:**
> Если нажать «Моё место», браузер превращает координаты в шестиугольник размером примерно в десятую квадратного километра. На сервер уходит только он. Точные координаты сервер даже не принимает.

## 6. Без ИИ (2:00–2:25)
**На экране:**
1. Переключатель «Без ИИ» (или кнопка «повторить без ИИ»).
2. Тот же запрос: карточки с метками «данные POI», тексты короче и шаблоннее.
3. Наезд на панель: «генерация: template, разбор: rules».

**Голос:**
> А если Claude недоступен — нет сети, лимит, сбой? Выключаем ИИ. Ответ всё равно есть: те же места и те же факты, просто тексты собраны по шаблонам из данных. Демо не падает, и это видно в панели.

## 7. Финал (2:25–2:40)
**На экране:** экран с логотипом Qadam и тремя строками:
- «16 сценариев: [цифра после eval]/16»;
- ссылка на репозиторий;
- «Данные © участники OpenStreetMap (ODbL)».

**Голос:**
> Qadam — честный советчик для прогулок по Астане. Код, данные и 16 тестовых сценариев — по ссылке. Спасибо!

## Запасной план
- Если UI (дорожка WEB) не готов к записи, сцены 2–4 и 6 снимаются по JSON-ответу API в браузере (`/docs` FastAPI) с наложенными подписями. Сцену 5 тогда показываем через вкладку Network.
- Если Claude отвечает медленно, записываем после прогрева кэша. Паузы длиннее 3 с вырезаем при монтаже.
- Финальные цифры eval берутся из `eval/report.md` после код-фриза (T80).
