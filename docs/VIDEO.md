# Qadam: демо-видео на 2:40 — сценарий записи (T82)

Формат: запись экрана 1920×1080, закадровый голос на русском. Загрузка на YouTube с доступом по ссылке.
Режим: **вариант A** — живой API с вектором, в панели «поиск: по смыслу и по словам». Мок не показываем.
Сцены сверены с живым интерфейсом 18.10.2026 на `main` cd6ebcd. **Сервер для записи — `main` b56caa7 или новее** (маршрут по тротуарам, граф по всему городу) (там исправлена утечка внутренних тегов в summary и в «почему»). Тексты Claude при записи будут немного другими: это нормально, факты и метки те же. В S5 summary, а у отдельных карточек «почему» может быть шаблонным вместо текста модели — это тоже нормально.

## Подготовка (10 минут)

**1. Два сервера из корня репозитория, каждый в своём окне Git Bash.**

Основной, с ИИ и вектором:
```bash
.venv/Scripts/python -m uvicorn app.api:app --port 8000
```
Второй, с выключенным ИИ — только для сцены 6:
```bash
export LLM_ENABLED=0
.venv/Scripts/python -m uvicorn app.api:app --port 8001
```

**2. Проверка.** http://localhost:8000/api/health → `"index": "ready"`, `"llm": "ok"`. http://localhost:8001/api/health → `"index": "ready"`, `"llm": "off (disabled)"`.

**3. Браузер.** Окно 1920×1080, масштаб 110%, курсор крупный, лишние вкладки закрыты.
- Вкладка 1: http://localhost:8000
- Вкладка 2: http://localhost:8001 — заранее нажать пресет «Прогулка у Mega» и дождаться ответа.

**4. Прогрев.** Во вкладке 1 по разу нажать пресеты S1, S3 и S5 и дождаться ответов. Первый ответ Claude идёт 6–13 с, повторный приходит из кэша почти сразу. Без прогрева паузы вырезаем при монтаже.

**5. Перед записью** в вкладке 1 нажать F5: чистый экран, панель «Какие данные использованы» свёрнута.

Что делают пресеты (проверено): подставляют текст запроса, место и время и сразу запускают поиск. Время ставится «вручную» на сегодняшнюю дату.

### 1. Хук (0:00–0:10)
**Нажимать:** ничего. Медленно провести курсором по карте и по пресетам.

**В кадре:** стартовый экран Qadam: карта Астаны, пресеты S1–S5, поле «Что хотите?».

**Голос:**
> Вы в Астане, у вас час. Куда пойти рядом прямо сейчас? Карты показывают сотни точек, но не отвечают на этот вопрос. Это Qadam.

### 2. S1: прогулка у Mega Silk Way (0:10–0:45)
**Нажимать:**
1. Пресет **«Прогулка у Mega»**. Текст запроса появляется сам.
2. Дождаться ответа: две карточки — NU Park и «Аллея мира и согласия» — и линия маршрута на карте. Японского сада больше нет: по тротуарам до него 23 мин, больше лимита 20 мин.
3. Навести курсор на первую карточку: «Почему», «Что делать», расстояние и минуты пешком (на b56caa7 по тротуарам — ≈1 км · 14 мин), время на месте.
4. Навести на блок **«Мини-маршрут»**: старт, NU Park, «Обратно к старту», общее время. Строка «По тротуарам: …» и пометка «Маршрут по тротуарам и переходам OSM … данные OSM бывают неполными».
5. Навести на метки карточки: «Из базы мест» или «Идея ИИ», «Часы не подтверждены», «Факты: OpenStreetMap».

**Голос:**
> Сценарий из кейса: «Я возле Mega Silk Way, хочу прогуляться 30–60 минут». Вместо длинного списка — два места. В каждой карточке: почему подходит, сколько идти, сколько там провести и что делать. Сверху мини-маршрут по тротуарам с возвращением к старту — около двух километров. А метки показывают, откуда факты и где идея ИИ, и что часы у этих мест не подтверждены.

### 3. S3: с ребёнком (0:45–1:10)
**Нажимать:**
1. Пресет **«С ребёнком»**. Место переключится на ТРЦ «Хан Шатыр», включится режим «С ребёнком».
2. Дождаться ответа: детские площадки с разными подписями, например «Детская площадка у Лепим и варим».
3. Раскрыть **«Какие данные использованы»** внизу ответа, навести на «Фильтры»: «с ребёнком», «категории: детская площадка, музей».

**Голос:**
> Теперь я с ребёнком. Qadam понял это из текста и включил режим: баров и клубов в ответе не будет. В открытых данных у большинства площадок нет названия, поэтому мы подписываем их по ближайшему месту, чтобы карточки не путались. Все фильтры видны в панели «Какие данные использованы».

### 4. S5: ночь и маршрут по тротуарам (1:10–1:45)
**Нажимать:**
1. Свернуть панель данных. Пресет **«Ночью»**: место — Монумент «Байтерек», время 23:30, режим «Ночь».
2. Навести на жёлтое предупреждение «Ночь: выбирайте освещённые людные места; обратно лучше на такси».
3. Навести на метки часов в карточках: «Открыто в 23:30» и «по данным OSM: ежедневно круглосуточно» или «… 12:00–02:00».
4. Навести на блок **«Мини-маршрут»**: строка «По тротуарам: 2,6 км · 35 мин · переходов 7, со светофором 5 · есть лестницы (8)».
5. Курсор на карту: сплошная линия по тротуарам и значки переходов (светофор, зебра). Можно приблизить колесом.
6. Раскрыть панель данных, навести на строку «по часам работы отсеяно …».

**Голос:**
> Половина двенадцатого ночи. Остаются только места, которые по данным открыты в это время, и сверху предупреждение о безопасности. Посмотрите на часы: «открыто в 23:30 по данным OSM». Места без подтверждённых часов ночью мы просто не показываем — панель говорит, сколько отсеяно. А «открыто сейчас» без надёжных данных Qadam не пишет никогда. И маршрут — не по прямой, а по тротуарам и переходам OpenStreetMap: два с половиной километра, семь переходов, пять со светофором, есть лестницы. Ночью это важно знать заранее.

### 5. Приватность (1:45–2:00)
**Нажимать:**
1. Кнопка **«Указать на карте»**, затем клик по карте рядом с Байтереком. Или **«Моё место»**, если браузер даст доступ к геолокации.
2. На карте закрашивается шестиугольник с подписью «Мы передаём только этот район ≈1,8 га». Под полем места: «На сервер уйдёт только ячейка H3 r10 … (≈1,8 га). Точные координаты остаются в браузере.» При «Моё место» ещё синяя точка; навести на неё: «Вы здесь (видно только вам, на наш сервер не отправляется)».
3. Нажать **«Обновить»** в плашке «Условия изменились». В ответе раскрыть панель данных и прокрутить до **«Что ушло на сервер»**: в JSON `"h3_cell": "…"`, координат нет.

**Голос:**
> Геолокация — это персональные данные, и мы её не собираем. Браузер превращает точку в шестиугольник размером примерно с квартал, около двух гектаров, и на сервер уходит только он. Вот что именно ушло: ячейка, без координат. Сервер координаты даже не принимает.

## Если что-то пошло не так
- **Ответ идёт дольше 15 с или пришла ошибка.** Повторить пресет: ответ возьмётся из кэша. При ошибке в интерфейсе есть кнопка «Повторить без ИИ», её можно показать как запасной путь.
- **Нет вектора** (в панели «поиск: по словам»). Значит, недоступен OpenRouter: проверить `/api/health`. Записывать все сцены в одном режиме поиска (вариант B ниже), режим посреди записи не менять.
- **Вариант B, без вектора:** перед запуском обоих серверов в Git Bash выполнить
  ```bash
  export OPENROUTER_API_KEY=
  export OPEN_ROUTER_KEY=
  ```
  Тогда `/api/health` → `"index": "ready (no key)"`, в панели «поиск: по словам, отбор — Claude». В PowerShell так не получится: `$env:X=""` удаляет переменную, и ключ снова берётся из `.env`.
