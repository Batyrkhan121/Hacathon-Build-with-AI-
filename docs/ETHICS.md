# Этика и приватность

## Локация
Закон РК «О персональных данных и их защите» № 94-V от 21.05.2013 требует собирать только нужные данные. Точная геолокация может быть персональными данными, поэтому мы её минимизируем.

| Мера | Где в коде |
|---|---|
| Сервер принимает только H3-ячейку r9 (≈0,1 км²) или id ориентира, координаты отклоняются | `LocationInput` в `app/schemas.py` (`extra="forbid"`, ровно одно поле); тест `test_request_rejects_raw_coordinates` |
| Поиск идёт от центра ячейки, а не от точки пользователя | `SearchContext.origin` |
| Ячейка и координаты не попадают в промпт Claude, только подпись района (см. «Кому уходят данные») | `app/generate.py` |
| В логах только id запроса, разрешение ячейки, счётчики и время; ни ячейки, ни текста запроса. История не хранится | `app/pipeline.py` (строка лога `recommend id=…`), `app/api.py` |
| Браузер переводит GPS в ячейку r9 только по кнопке «Моё место», на карте рисуется шестиугольник | `web/app.js`, `web/map.js` |

## Кому уходят данные
Сверено по коду 19.10.

| Кому | Что уходит | Чего не уходит | Где в коде |
|---|---|---|---|
| **Anthropic (Claude)** | Текст запроса (как данные, не как инструкции) и подпись района: «у EXPO», «ваш район (≈0,1 км²) у …». Для карточек ещё кандидаты: названия мест, теги, часы, расстояния в метрах от центра поиска | H3-ячейка и координаты | `app/query_parser.py` (`_user_prompt`), `app/generate.py` (`_context_view`, `_candidate_view`) |
| **Google (Gemini API)** | Только текст запроса, чтобы получить его вектор (`embed_query`, если задан `GEMINI_API_KEY`). В режиме без ИИ не вызывается | Район, ячейка, координаты | `app/llm.py`, `app/pipeline.py` (шаг 4) |
| **Open-Meteo** | Координаты центра поиска (центр ячейки или ориентира), округлённые до 2 знаков (≈1 км) | Текст запроса, ячейка | `app/weather.py` (`round(..., 2)`) |
| **OpenStreetMap tiles, unpkg** (из браузера) | Сервер тайлов `tile.openstreetmap.org` видит IP и участок карты, который вы смотрите, после «Моё место» это район ячейки. CDN unpkg (Leaflet, h3-js) видит IP | Текст запроса | `web/map.js`, `web/index.html` |

- **Не передаются третьим сторонам:** H3-ячейка и история запросов. Ячейка используется только на нашем сервере, чтобы найти центр поиска.
- **Что всё-таки косвенно говорит о месте.** Подпись района и расстояния до ближайших мест, которые получает Claude, позволяют примерно понять район, но не точку внутри ячейки.
- **Что хранится на сервере.** Дисковый кэш `data/cache/` с ответами модели и векторами запросов, ключ — хэш промпта. Ячейки в кэше нет, поле `raw_query` из ответа разбора вырезается (`REDACTED_FIELDS`). Отдельной истории запросов нет.
- **Gemini на бесплатном тарифе.** Пока ключ Gemini на бесплатном тарифе, по условиям Gemini API Google может использовать отправленные тексты запросов для улучшения своих продуктов. После включения биллинга (платный тариф) это условие не действует. **Перед сдачей проверить тариф ключа.**

## Достоверность
- **Факты из данных.** Код считает расстояние, время пешком, часы и адрес по записи POI. На карточке указаны `facts_sources`, у записи есть дата `fetched_at`.
- **Часы с уверенностью** (`app/hours.py`). Статус open, closed или unknown всегда идёт с уверенностью high, medium или low. Нет данных или формат непонятен — пишем unknown/low и «проверьте перед визитом». Часы есть только у 27% мест, так что такая пометка встречается часто.
- **Никакого «открыто сейчас» без open/high.** Это правило валидатора, и eval проверяет его в каждом сценарии.
- **ИИ помечен.** На карточке `idea_source: generated`, у описаний `description_source: llm_generated`.
- **Prompt-injection.** Запрос передаётся модели как данные, ответ разбирается строго по схеме. Проверяет сценарий E5.
- **Нет данных — так и пишем.** Если доступность для коляски не указана (так у 95% мест), пишем «не подтверждено» (E8). Если рядом пусто, говорим об этом прямо (E11).

## Безопасность пользователя
- Ночью предупреждаем о безопасности и оставляем только места, которые подтверждённо открыты или работают допоздна/круглосуточно (S5, E2).
- С ребёнком не предлагаем бары и клубы (S3, E4).
- Если Claude недоступен, ответ всё равно собирается по данным (E10).

## Данные и лицензии
- OpenStreetMap: ODbL, атрибуция в `data_used.sources` и на карте. Wikidata: CC0. Open-Meteo: погода без ключа.
- **Для публикации.** `data/processed/poi.jsonl` — производная база данных OpenStreetMap под лицензией **ODbL 1.0**. Нужна атрибуция «© участники OpenStreetMap», и база (с нашими дополнениями) распространяется под той же лицензией (share-alike).
- 2GIS и Яндекс не используем: их оферты запрещают хранить данные.

## Риски
| Риск | Что делаем |
|---|---|
| OSM устаревает, часов мало | Дата снимка, честное unknown, обновление одной командой |
| Лимиты и отказы Claude | Запасная модель Haiku, дисковый кэш, шаблоны |
| Нет эмбеддингов | Лексический поиск. Качество меряем eval в обоих режимах |
| Смещение к «популярным» | Популярность — прокси по полноте записи (вес 0,10). Отзывов и рейтингов в данных нет |
| Временные события и закрытые места | В данных их нет, поэтому ничего не придумываем. **План:** официальная афиша с меткой «временное» |
