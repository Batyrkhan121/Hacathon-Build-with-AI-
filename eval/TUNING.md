# Подбор качества (T70, QUALITY): до и после

Каждый шаг — одно изменение и одна строка в таблице. Изменение остаётся, только если основной eval не падает ни в одном сценарии.

- **Основной eval** (`eval/scenarios.yaml`, 16 сценариев) проверяет, что ответ допустим. Это защита от регрессий.
- **Пробы** (`eval/probes.yaml`, 9 штук) проверяют, что лучший вариант стоит первым. Они меряют эффект отдельного рычага.
- Прогоны без Claude (`--no-llm`), данные `data/processed/poi.jsonl` (1228 POI), без эмбеддингов (лексика).
- Прогоны с Claude — после сигнала «ключ в .env».

```bash
python -m eval.run_eval --no-llm --out <папка>
python -m eval.run_eval --no-llm --scenarios eval/probes.yaml --out <папка>
```
