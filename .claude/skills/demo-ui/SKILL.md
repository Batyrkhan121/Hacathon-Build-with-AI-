# Демо-интерфейс (дорожка WEB)

Аргументы: $ARGUMENTS

Жюри открывает демо и за 10 секунд должно получить полезный ответ (критерий 4: UX и понятность). Стек: чистый HTML/CSS/JS (ES-модули), без сборщика. Все внешние скрипты подключаются с точной версией.

## Файлы
`web/index.html`, `web/styles.css`, `web/app.js`, `web/i18n.js`, при желании `web/api.js`, `web/map.js`.
`web/mock/answer_sample.json` принадлежит интегратору: читать можно, менять нельзя. Он валиден по `Answer` из `app/schemas.py`.

## Библиотеки (локально)
- Leaflet 1.9.4 и h3-js 4.1.0 (глобальный объект `h3`) лежат в `web/vendor/leaflet-1.9.4/` и `web/vendor/h3-js-4.1.0/` вместе с лицензиями; `index.html` подключает их относительными путями. Браузер обращается только к нашему серверу и тайлам OSM.
- Обновление версии: новая папка `<имя>-<версия>/`, сверка sha256 по `web/vendor/README.md` и таблица там же. `integrity` для своих файлов не ставим (см. README).
- Тайлы: стандартные OSM `https://tile.openstreetmap.org/{z}/{x}/{y}.png` (CARTO basemaps с 2026 года отдают без ключа заглушку «API KEY REQUIRED»). Атрибуция обязательна: «© OpenStreetMap contributors». Сервер тайлов видит IP и участок карты, это записано в docs/ETHICS.md.

## Экран
Слева панель (на мобильном снизу), справа карта.
1. Строка запроса, кнопка «Подсказать».
2. Где я:
   - выпадающий список ориентиров (`GET /api/landmarks`; в режиме мока берём из `data/landmarks.json`);
   - кнопка «Моё местоположение»: `navigator.geolocation` → `h3.latLngToCell(lat, lng, 9)`. Наружу уходит только ячейка. На карте рисуем полигон ячейки (`h3.cellToBoundary`) с подписью «Мы передаём только этот район ≈0,1 км²». Это фишка приватности, её показываем в видео.
3. Чипы-фильтры: время 30 / 60 / 120 мин, «с ребёнком», «доступная среда», «в помещении», «нас 3–5». Они уходят в `overrides`.
4. Машина времени для демо: «сейчас / 10:00 / 19:00 / 23:30». Уходит в `at` в формате ISO с +05:00.
5. Пресеты S1–S5 (одна кнопка подставляет запрос, ориентир и время):
   - S1: «Я возле Mega Silk Way, хочу прогуляться 30–60 минут» → mega_silk_way, 15:00;
   - S2: «Хочу тихое место с кофе и розеткой» → expo, 11:00;
   - S3: «Еду с ребёнком — где рядом площадка или музей с интерактивом?» → khan_shatyr, 12:00, с ребёнком;
   - S4: «Я турист, у меня 2 часа перед вылетом» → baiterek, 16:00, режим «турист до вылета» (`tourist: true`, `departure_in_min: 120`), не airport_nqz: у аэропорта в данных почти пусто, сервер сам вычитает дорогу в аэропорт;
   - S5: «Ищу необычную ночную активность» → baiterek, 23:30.
6. Язык ru / kk / en: переводит интерфейс и уходит в `lang`.

## Карточка (`Answer.cards[i]`)
- Номер, название, иконка категории; «≈350 м · 5 мин пешком»; «на месте 40–60 мин».
- «Почему:» `why`; «Что делать:» `what_to_do`.
- Бейджи:
  - `idea_source`: «Данные POI» (зелёный) или «Идея ИИ» (фиолетовый, с подсказкой «сгенерировано моделью, проверьте»);
  - часы: open/high → «Открыто (OSM)», open/medium → «Вероятно открыто», unknown → «Часы не подтверждены», closed → «Закрыто»; рядом показываем `open_note`;
  - `data_confidence` полоской;
  - `facts_sources` мелким текстом.
- Кнопки «На карте» и «Маршрут». Маршрут рисуем полилинией по `route.path`, с номерами остановок и итогом «≈N мин, M м».
- Внизу: `summary`, `warnings` жёлтыми плашками, `disclaimer`.
- Раскрывающаяся панель «Какие данные использованы» из `data_used`: место, время, погода, фильтры, источники, парсер и генерация, модель.

## Работа с API
- `POST /api/recommend` с телом `RecommendRequest`. Таймаут 25 с через AbortController.
- Скелетон во время загрузки. При ошибке кнопка «Повторить без ИИ» (`use_llm: false`).
- Режим мока: `?mock=1` → `fetch('mock/answer_sample.json')`. Путь относительный, поэтому работает и при `python -m http.server 5500` из корня (`/web/?mock=1`), и при отдаче через FastAPI. Ориентиры в моке берём через `fetch('../data/landmarks.json')`.
- Ни одного запроса с сырыми координатами. Проверь вкладку Network: в теле только `h3_cell` или `landmark_id`.

## Качество
- Мобильная вёрстка от 360 px; видимый фокус; `aria-label` на иконках; контраст AA.
- Никаких `localStorage`, кроме выбранного языка (в try/catch).
- Ревью и полировка: `/ecc:frontend-design-direction`, `/ecc:make-interfaces-feel-better`, `/ecc:accessibility`.
- Проверка в браузере: Claude in Chrome, если доступен. Иначе опиши ручной сценарий проверки в отчёте.
