# Qadam: варианты анимации поиска

Изолированная страница `index.html`, без зависимостей и API. Не подключена к прототипу.

Варианты: 1 — четыре следа; 2 — следы к маркеру; 3 — компактная пара над skeleton-карточками.

Reference lock: существующий Qadam/Airbnb direction (белая поверхность, системный шрифт, синий #245fc5, жёлтый декоративный акцент); идея следов — от пользователя. Motion craft: Refero references/motion.md — обратная связь, короткое появление, отсутствие задержки готового результата, reduced motion. SVG — собственные простые пиктограммы подошв. Линия варианта 2 не обозначает настоящий маршрут.

Решения: единый контекст поиска для честного сравнения; цикл 2 с с последовательными фазами; выбор ожидания 700/3000/8000 мс только для демонстрации. Результат/отмена немедленно прекращают анимацию. Пауза останавливает и CSS, и таймер. Режим reduced motion системный + ручной. Вариант выбирается якорем #1, #2, #3; сбор голосов отсутствует.

Для интеграции сначала выбрать вариант. Ожидание реального приложения не привязывать к длительности анимации. Тексты перевести на kk/en через существующий словарь. Никаких изменений в web/, app/ или design/delivery/demo/.

Проверено в Chrome/Playwright: все 3 варианта на ширинах 360, 390, 768, 1440; отсутствие горизонтального overflow; досрочное завершение; отмена; пауза/продолжение таймера; prefers-reduced-motion; фактическое изменение opacity анимации. 16 проверок, ошибок JavaScript нет. Визуально просмотрены desktop и mobile. Реальные устройства не использовались.

Публичная демонстрация: https://qadam-walks-prototype.nifty-buddy-6738.chatgpt.site/animations/
