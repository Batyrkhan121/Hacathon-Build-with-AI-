# Qadam · проверка UX-версии 2

Проверен дизайнерский стенд `design/delivery/demo`, а не готовность production или исправления из QA-ветки Райымбека. Проверки выполнены в Google Chrome через Playwright, без обращения к API и настоящим моделям.

## Результат

- **33/33 проверки взаимодействия** прошли на 360×800 и 1280×720. Скрипт — `check-ux.cjs`, подробный результат — `UX-CHECKS.json`.
- Все **41 кадр** пересняты без специальных упрощений раскладки для capture. В `manifest.json`: `errors: []`, нет горизонтального переполнения или ошибок JavaScript.
- Проверены языки KK/RU/EN, пять сценариев, отправка и повторная отправка, изменение и отмена черновика, отмена загрузки, details с клавиатуры, карта, возврат к карточке и выход из выбора точки.
- Зеленый статус только при `open + high`. Unknown и closed+medium сохраняют неопределённость. Предупреждения о часах видны до раскрытия подробностей.
- Фокус возвращается к вызвавшей кнопке карты или полю запроса после отмены загрузки. Escape отменяет выбор на карте.
- Макет главной и ответа проверен визуально на телефоне и desktop. Системный шрифт поддерживает казахские буквы; внешние шрифты не добавлены.

## Исправленные замечания

1. Убрано расхождение между живым preview и PNG: форма сворачивается по состоянию результата, а не по параметру capture.
2. Отмена редактирования восстанавливает последний отправленный запрос и параметры.
3. Старый ответ сохраняется при изменении условий и явно помечается как устаревший.
4. Возврат с выбора точки снимает обработчик карты; Escape работает так же.
5. Отмена загрузки действительно останавливает ожидающий ответ.
6. Удалено безусловное «три идеи» из RU/EN, сохранено предупреждение о скором закрытии; переведены адреса-примеры.
7. Текст what, адрес, теги, полнота и источники находятся внутри раскрытия; часы и источник идеи остаются снаружи.

## Запуск

```sh
# Из design/delivery, в первом терминале:
python3 -m http.server 5512 --bind 127.0.0.1

# Во втором терминале, с установленным Playwright и Chrome:
node check-ux.cjs
node capture.cjs
```

Для существующей установки Playwright можно задать `PLAYWRIGHT_MODULE`; `check-ux.cjs` принимает `QADAM_PREVIEW_URL` и `PLAYWRIGHT_CHANNEL`.

## Практические ограничения

- Настоящие API, модели, геолокация и безопасность не проверялись. Все ответы — демонстрационные fixtures, с видимой пометкой.
- Мок не рассчитывает рекомендации заново для произвольных параметров: это поведение интерфейса, а не проверка алгоритма.
- Внешние OSM-плитки зависят от сети; предусмотрен отдельный кадр ошибки. При реальной интеграции нужен обработчик tileerror, указанный в CONTRACT-AND-COVERAGE.md.
- Полный Python pytest/ruff здесь не запускался успешно: в доступном Python отсутствуют модули pytest и ruff. Файлы backend и production UI не менялись. Результат 33/33 относится только к описанной браузерной проверке.
- Ранее проверенные Pydantic-fixtures не изменены; этот отчёт не закрывает P1/P2 из `qa/security-audit`.
