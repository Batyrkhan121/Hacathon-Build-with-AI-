# Батырхан Абылкан Portfolio

Статическое портфолио с 14 проектами, фильтрами, поиском, карточками, исходными интерфейсными макетами Love Quest, демонстрационным frontend Qadam и резюме PDF.

## Локальный просмотр

Запустить любой статический HTTP-сервер с корнем `dist`. Например: `python -m http.server 8765 --directory dist`.

## Проверка и публикация

`node scripts/check.mjs`

Render Static Site: ветка `portfolio-showcase`, build command `node scripts/check.mjs`, publish directory `dist`. Зависимости не требуются; `SKIP_INSTALL_DEPS=true`.

## Демо и источники

- Love Quest: исходные HTML-макеты из публичного репозитория Love_quest, снабжённые отдельной демонстрационной навигацией. Это прототип с примерами данных, не работающая авторизация или LLM.
- Qadam: публичный frontend из Hacathon-Build-with-AI- в штатном mock-режиме. Использует локальные файлы примеров; внешние ИИ-ключи не нужны.
- Tarih и TaskFlow: прямые ссылки на отдельные Render-приложения.
- Схемы на обложках остальных проектов являются иллюстрациями, а не скриншотами приложений.

Исходные проекты и вклад описаны в карточках. Закрытые репозитории не публикуются этим сайтом.

Qadam: код MIT. Leaflet: BSD-2-Clause, H3: Apache-2.0; исходные файлы библиотек и их лицензии сохранены в демо. Картографические данные и атрибуция OpenStreetMap сохранены в исходном frontend.
